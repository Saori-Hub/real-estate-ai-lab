# Real Estate AI Lab

## Overview
This project builds a simple machine learning model to predict real estate prices based on property area.

## What it does
- Reads dataset using pandas
- Visualizes relationship between area and price
- Builds Linear Regression model
- Evaluates with R² and MAE
- Predicts price from new area input

## Tech Stack
Python / Pandas / Matplotlib / scikit-learn

## Result
Basic price prediction model successfully implemented and pushed to GitHub.
